# Time Series Analysis & Forecasting 📈

This repository contains a collection of Jupyter notebooks exploring **time series analysis, forecasting, and web scraping for financial and climate data**.  
The project covers classic statistical models, deep learning approaches, and modern forecasting frameworks.

---

## 📂 Repository Structure

| File / Notebook | Description |
|-----------------|-------------|
| **01_time_series.ipynb** | Introduction to time series analysis with basic visualization and decomposition. |
| **02_time_series.ipynb** | Extended exploration of time series concepts and techniques. |
| **03_time-series_tf.ipynb** | Time series forecasting using TensorFlow-based deep learning models. |
| **04_time_searies_prophet.ipynb** | Forecasting with Facebook Prophet. |
| **05_jena_prophet_model.ipynb** | Prophet model applied to the Jena Climate dataset. |
| **06_time_series.ipynb** | Additional experiments with time series forecasting. |
| **07_webscrapping_stock_market_data.ipynb** | Web scraping stock market data for analysis. |
| **08_web_scrapping.ipynb** | General-purpose web scraping for time series datasets. |
| **09_arima.ipynb** | ARIMA model for univariate time series forecasting. |
| **10_SARIMA.ipynb** | SARIMA model for seasonal time series forecasting. |

---

## 📊 Datasets

| Dataset | Description |
|---------|-------------|
| **AirPassengers.csv** | Monthly airline passenger numbers (1949–1960). |
| **DailyDelhiClimateTrain.csv** | Training dataset containing climate data from Delhi. |
| **DailyDelhiClimateTest.csv** | Test dataset for Delhi climate forecasting. |
| **jena_climate_2009_2016.csv** | Jena Climate dataset (2009–2016), commonly used in time series experiments. |

---

## 🚀 Features

- Time series visualization and decomposition  
- ARIMA & SARIMA models for forecasting  
- Deep learning approaches with TensorFlow  
- Forecasting with Prophet  
- Real-world applications on climate and financial datasets  
- Web scraping for stock market and other time series data
